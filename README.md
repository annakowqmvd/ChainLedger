# ChainLedger

ChainLedger enables real-time, distributed data processing through scalable, auto-scaling cluster management services.

ChainLedger is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ChainLedger.git`
2. `cd ChainLedger`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ChainLedger, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
